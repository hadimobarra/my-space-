1f:Tb46,<h2 id="introduction">Introduction</h2>
<p>Performance is critical for user experience and SEO. Google's Core Web Vitals have made performance optimization more important than ever.</p>
<h2 id="core-web-vitals">Core Web Vitals</h2>
<h3 id="largest-contentful-paint-lcp">Largest Contentful Paint (LCP)</h3>
<p>LCP measures loading performance. Aim for LCP under 2.5 seconds.</p>
<ul>
<li>Optimize images with proper formats (WebP, AVIF)</li>
<li>Use CDN for static assets</li>
<li>Implement lazy loading</li>
</ul>
<h3 id="first-input-delay-fid">First Input Delay (FID)</h3>
<p>FID measures interactivity. Aim for FID under 100ms.</p>
<ul>
<li>Code splitting</li>
<li>Reduce JavaScript execution time</li>
<li>Use web workers for heavy computations</li>
</ul>
<h3 id="cumulative-layout-shift-cls">Cumulative Layout Shift (CLS)</h3>
<p>CLS measures visual stability. Aim for CLS under 0.1.</p>
<ul>
<li>Set explicit dimensions for images</li>
<li>Reserve space for dynamic content</li>
<li>Avoid inserting content above existing content</li>
</ul>
