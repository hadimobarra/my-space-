3:T41f4,<h2 id="types-are-a-programming-language">Types are a programming language</h2>
<p>TypeScript's type system is Turing-complete, which in practice means you can compute types from other types. Once you see it as a small functional language — with <em>functions</em> (generic types), <em>conditionals</em> (conditional types), <em>loops</em> (recursion and mapped types) and <em>string manipulation</em> (template literal types) — advanced library types stop looking like magic.</p>
<h2 id="generic-types-are-functions">Generic types are functions</h2>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">Box</span>&#x3C;T> = { <span class="hljs-attr">value</span>: T };       <span class="hljs-comment">// a function from T to a type</span>
<span class="hljs-keyword">type</span> <span class="hljs-title class_">StringBox</span> = <span class="hljs-title class_">Box</span>&#x3C;<span class="hljs-built_in">string</span>>;     <span class="hljs-comment">// calling it</span>
</code></pre>
<h2 id="conditional-types-are-if-statements">Conditional types are <code>if</code> statements</h2>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">IsString</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span> ? <span class="hljs-literal">true</span> : <span class="hljs-literal">false</span>;

<span class="hljs-keyword">type</span> A = <span class="hljs-title class_">IsString</span>&#x3C;<span class="hljs-string">"hi"</span>>; <span class="hljs-comment">// true</span>
<span class="hljs-keyword">type</span> B = <span class="hljs-title class_">IsString</span>&#x3C;<span class="hljs-number">42</span>>;   <span class="hljs-comment">// false</span>
</code></pre>
<p><code>extends</code> here means "is assignable to". Combined with <strong><code>infer</code></strong>, conditional types also do pattern matching — they can pull pieces out of a type:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ElementType</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-title function_">readonly</span> (infer U)[] ? U : <span class="hljs-built_in">never</span>;
<span class="hljs-keyword">type</span> <span class="hljs-title class_">Awaited2</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-title class_">Promise</span>&#x3C;infer U> ? <span class="hljs-title class_">Awaited2</span>&#x3C;U> : T;
<span class="hljs-keyword">type</span> <span class="hljs-title class_">ReturnOf</span>&#x3C;F> = F <span class="hljs-title function_">extends</span> (...<span class="hljs-attr">args</span>: <span class="hljs-built_in">any</span>[]) => infer R ? R : <span class="hljs-built_in">never</span>;

<span class="hljs-keyword">type</span> E = <span class="hljs-title class_">ElementType</span>&#x3C;<span class="hljs-built_in">string</span>[]>;            <span class="hljs-comment">// string</span>
<span class="hljs-keyword">type</span> P = <span class="hljs-title class_">Awaited2</span>&#x3C;<span class="hljs-title class_">Promise</span>&#x3C;<span class="hljs-title class_">Promise</span>&#x3C;<span class="hljs-built_in">number</span>>>>; <span class="hljs-comment">// number (recursion!)</span>
</code></pre>
<h2 id="the-distributive-surprise">The distributive surprise</h2>
<p>When the checked type is a <strong>naked type parameter</strong> and you pass a union, the conditional is applied to each member separately:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ToArray</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-built_in">unknown</span> ? T[] : <span class="hljs-built_in">never</span>;
<span class="hljs-keyword">type</span> X = <span class="hljs-title class_">ToArray</span>&#x3C;<span class="hljs-built_in">string</span> | <span class="hljs-built_in">number</span>>; <span class="hljs-comment">// string[] | number[]  (not (string | number)[])</span>
</code></pre>
<p>That's usually what you want (it's how <code>Exclude</code> and <code>Extract</code> work), but sometimes it isn't. Wrap both sides in a tuple to turn distribution off:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ToArrayNonDist</span>&#x3C;T> = [T] <span class="hljs-keyword">extends</span> [<span class="hljs-built_in">unknown</span>] ? T[] : <span class="hljs-built_in">never</span>;
<span class="hljs-keyword">type</span> Y = <span class="hljs-title class_">ToArrayNonDist</span>&#x3C;<span class="hljs-built_in">string</span> | <span class="hljs-built_in">number</span>>; <span class="hljs-comment">// (string | number)[]</span>
</code></pre>
<p>The same trick gives a reliable <code>IsNever</code> check, because <code>never</code> is an empty union and distributing over it yields <code>never</code>:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">IsNever</span>&#x3C;T> = [T] <span class="hljs-keyword">extends</span> [<span class="hljs-built_in">never</span>] ? <span class="hljs-literal">true</span> : <span class="hljs-literal">false</span>;
</code></pre>
<h2 id="mapped-types-are-loops-over-keys">Mapped types are loops over keys</h2>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ReadonlyDeep</span>&#x3C;T> = {
  <span class="hljs-keyword">readonly</span> [K <span class="hljs-keyword">in</span> keyof T]: T[K] <span class="hljs-keyword">extends</span> <span class="hljs-built_in">object</span> ? <span class="hljs-title class_">ReadonlyDeep</span>&#x3C;T[K]> : T[K];
};
</code></pre>
<p>Since TypeScript 4.1, the <strong><code>as</code> clause</strong> lets you rename or filter keys while mapping:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">Getters</span>&#x3C;T> = {
  [K <span class="hljs-keyword">in</span> keyof T <span class="hljs-keyword">as</span> <span class="hljs-string">`get<span class="hljs-subst">${Capitalize&#x3C;<span class="hljs-built_in">string</span> &#x26; K>}</span>`</span>]: <span class="hljs-function">() =></span> T[K];
};

<span class="hljs-keyword">type</span> <span class="hljs-title class_">User</span> = { <span class="hljs-attr">name</span>: <span class="hljs-built_in">string</span>; <span class="hljs-attr">age</span>: <span class="hljs-built_in">number</span> };
<span class="hljs-keyword">type</span> <span class="hljs-title class_">UserGetters</span> = <span class="hljs-title class_">Getters</span>&#x3C;<span class="hljs-title class_">User</span>>;
<span class="hljs-comment">// { getName: () => string; getAge: () => number }</span>

<span class="hljs-comment">// Filtering: returning `never` from `as` removes the key</span>
<span class="hljs-keyword">type</span> <span class="hljs-title class_">OnlyFunctions</span>&#x3C;T> = {
  [K <span class="hljs-keyword">in</span> keyof T <span class="hljs-keyword">as</span> T[K] <span class="hljs-title function_">extends</span> (...<span class="hljs-attr">args</span>: <span class="hljs-built_in">any</span>[]) => <span class="hljs-built_in">any</span> ? K : <span class="hljs-built_in">never</span>]: T[K];
};
</code></pre>
<h2 id="template-literal-types-are-string-functions">Template literal types are string functions</h2>
<p>Template literal types concatenate and — with <code>infer</code> — <em>parse</em> strings at the type level:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">Split</span>&#x3C;S <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>, D <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>> =
  S <span class="hljs-keyword">extends</span> <span class="hljs-string">`<span class="hljs-subst">${infer Head}</span><span class="hljs-subst">${D}</span><span class="hljs-subst">${infer Tail}</span>`</span>
    ? [<span class="hljs-title class_">Head</span>, ...<span class="hljs-title class_">Split</span>&#x3C;<span class="hljs-title class_">Tail</span>, D>]
    : [S];

<span class="hljs-keyword">type</span> <span class="hljs-title class_">Parts</span> = <span class="hljs-title class_">Split</span>&#x3C;<span class="hljs-string">"a.b.c"</span>, <span class="hljs-string">"."</span>>; <span class="hljs-comment">// ["a", "b", "c"]</span>
</code></pre>
<h2 id="project-1-a-type-safe-router">Project 1: a type-safe router</h2>
<p>Let's extract route parameters from a path string, so <code>params</code> is fully typed:</p>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">ExtractParams</span>&#x3C;<span class="hljs-title class_">Path</span> <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>> =

    ? { [K <span class="hljs-keyword">in</span> <span class="hljs-title class_">Param</span> | keyof <span class="hljs-title class_">ExtractParams</span>&#x3C;<span class="hljs-string">`/<span class="hljs-subst">${Rest}</span>`</span>>]: <span class="hljs-built_in">string</span> }
    : <span class="hljs-title class_">Path</span> <span class="hljs-keyword">extends</span> <span class="hljs-string">`<span class="hljs-subst">${<span class="hljs-built_in">string</span>}</span>:<span class="hljs-subst">${infer Param}</span>`</span>
      ? { [K <span class="hljs-keyword">in</span> <span class="hljs-title class_">Param</span>]: <span class="hljs-built_in">string</span> }
      : {};

<span class="hljs-keyword">function</span> route&#x3C;P <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>>(
  <span class="hljs-attr">path</span>: P,
  <span class="hljs-attr">handler</span>: <span class="hljs-function">(<span class="hljs-params"><span class="hljs-attr">params</span>: <span class="hljs-title class_">ExtractParams</span>&#x3C;P></span>) =></span> <span class="hljs-built_in">void</span>

<span class="hljs-title function_">route</span>(<span class="hljs-string">"/users/:userId/posts/:postId"</span>, <span class="hljs-function">(<span class="hljs-params">params</span>) =></span> {
  params.<span class="hljs-property">userId</span>; <span class="hljs-comment">// string ✅</span>

<p>The type recursively peels off <code>:param/</code> segments and merges the found names into one object type. This is the same technique used by typed routers such as those in Hono and TanStack Router.</p>
<h2 id="project-2-a-typed-deep-get">Project 2: a typed deep <code>get</code></h2>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">Paths</span>&#x3C;T> = T <span class="hljs-keyword">extends</span> <span class="hljs-built_in">object</span>

      [K <span class="hljs-keyword">in</span> keyof T &#x26; <span class="hljs-built_in">string</span>]: T[K] <span class="hljs-keyword">extends</span> <span class="hljs-built_in">object</span>

  : <span class="hljs-built_in">never</span>;

<span class="hljs-keyword">const</span> config = { <span class="hljs-attr">server</span>: { <span class="hljs-attr">port</span>: <span class="hljs-number">8080</span>, <span class="hljs-attr">tls</span>: { <span class="hljs-attr">enabled</span>: <span class="hljs-literal">true</span> } } };

<p>The <code>{ ... }[keyof T]</code> pattern at the end of <code>Paths</code> is a common idiom: build an object type whose <em>values</em> are what you want, then index it with all its keys to get a union of the values.</p>
<h2 id="keeping-the-compiler-happy">Keeping the compiler happy</h2>
<p>Type-level code has real costs:</p>
<ul>
<li><strong>Recursion limits.</strong> TypeScript caps instantiation depth (about 50 for non-tail recursion, and up to 1,000 for tail-recursive conditional types). Write recursive types in tail position by passing an accumulator:</li>
</ul>
<pre><code class="hljs language-ts"><span class="hljs-keyword">type</span> <span class="hljs-title class_">Join</span>&#x3C;T <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>[], D <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>, <span class="hljs-title class_">Acc</span> <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span> = <span class="hljs-string">""</span>> =
  T <span class="hljs-keyword">extends</span> [infer H <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>, ...infer R <span class="hljs-keyword">extends</span> <span class="hljs-built_in">string</span>[]]
    ? <span class="hljs-title class_">Join</span>&#x3C;R, D, <span class="hljs-title class_">Acc</span> <span class="hljs-keyword">extends</span> <span class="hljs-string">""</span> ? H : <span class="hljs-string">`<span class="hljs-subst">${Acc}</span><span class="hljs-subst">${D}</span><span class="hljs-subst">${H}</span>`</span>>
    : <span class="hljs-title class_">Acc</span>;

<span class="hljs-keyword">type</span> J = <span class="hljs-title class_">Join</span>&#x3C;[<span class="hljs-string">"a"</span>, <span class="hljs-string">"b"</span>, <span class="hljs-string">"c"</span>], <span class="hljs-string">"-"</span>>; <span class="hljs-comment">// "a-b-c"</span>
</code></pre>
<ul>
<li><strong>Editor performance.</strong> Deep types on hot paths slow down IntelliSense for everyone. Check with <code>tsc --extendedDiagnostics</code> and <code>--generateTrace</code>.</li>
<li><strong>Readability.</strong> Name intermediate types and add a short comment explaining <em>what</em> the type computes. Future you will need it.</li>
</ul>
<h2 id="conclusion">Conclusion</h2>
<p>Conditional types are branching, <code>infer</code> is pattern matching, mapped types are loops, and template literals are string processing.
